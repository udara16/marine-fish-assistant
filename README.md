# 🐟 Sri Lanka Marine Fishing Assistant (ධීවර සහයක)

ශ්‍රී ලාංකික ධීවර ප්‍රජාව සහ මුහුදු ආශ්‍රිතව කටයුතු කරන පිරිස් සඳහා තත්‍ය කාලීන සමුද්‍ර කාලගුණය සහ මත්ස්‍ය කලාප අනාවැකි සරල සිංහලෙන් ලබාදෙන සැහැල්ලු වෙබ් යෙදුමකි (Web App).

---

## 🌟 ප්‍රධාන විශේෂාංග (Key Features)

* **තත්‍ය කාලීන සමුද්‍ර කාලගුණය:** රළ උස (Wave Height), සුළඟේ වේගය (Wind Speed), සාගර ජල උෂ්ණත්වය සහ වායුගෝලීය පීඩනය ක්ෂණිකව බලාගැනීම.
* **මුහුදු ආරක්ෂිත තත්ත්වය (Safety Status):** රළ සහ සුළඟේ වේගය අනුව මුහුදු යාම සුදුසුද නැද්ද යන්න පිළිබඳ වර්ණ කේත සහිත ක්ෂණික පණිවිඩ (Safe / Warning / Danger).
* **මත්ස්‍ය කලාප අනාවැකි:** වායුගෝලීය පීඩන විචලනයන් පදනම් කරගෙන මසුන් ගැවසීමේ සම්භාවිතාව සහ සුදුසු ගැඹුර තක්සේරු කිරීම.
* **AI Justification Note:** ලබාදුන් අනාවැකියට පාදක වූ විද්‍යාත්මක සහ කාලගුණික හේතු සරලව පැහැදිලි කිරීම.
* **දේශීය කලාප සහ GPS පහසුකම:** ලංකාවේ ප්‍රධාන වෙරළබඩ කලාප ලැයිස්තුවකින් තෝරාගැනීම හෝ Live GPS මඟින් වත්මන් ස්ථානයේ තොරතුරු ලබාගැනීම.
* **100% Client-Side:** Server හෝ API Keys අවශ්‍ය නැත; GitHub Pages හරහා සම්පූර්ණයෙන්ම නොමිලේ ක්‍රියාත්මක කළ හැක.

---

## 📊 දත්ත මූලාශ්‍ර (Data Sources)

1. **Open-Meteo Marine API:** ECMWF සහ Copernicus Marine Service ආකෘති මඟින් සපයන රළ උස සහ සාගර තත්ත්ව දත්ත.
2. **Open-Meteo Weather API:** ජාත්‍යන්තර සංඛ්‍යාත්මක කාලගුණ ආකෘති මඟින් සපයන සුළං වේගය, උෂ්ණත්වය සහ වායු පීඩනය.
3. **Solunar & Barometric Fish Feeding Models:** පීඩනය සහ මසුන්ගේ පිහිනුම් මුත්‍රාශයේ (Swim Bladder) සමතුලිතතාවය අතර පවතින ජීව-විද්‍යාත්මක සම්බන්ධතා ආකෘති.

---

## ⚠️ විශ්වසනීයත්වය (Reliability & Advisory)

* **නිරවද්‍යතාවය:** ආසන්න වශයෙන් **80% - 85%**.
* කාලගුණ සහ රළ පිළිබඳ දත්ත චන්ද්‍රිකා සහ සාගර බෝයාවන් (Marine Buoys) මඟින් නිරන්තරයෙන් යාවත්කාලීන වන බැවින් ඉහළ නිරවද්‍යතාවයකින් යුක්ත වේ.
* මසුන් ගැවසීම ජල ධාරා (Currents), ප්ලවාංග (Chlorophyll) සහ ආලෝකය මත ද වෙනස් විය හැකි බැවින් මෙය මඟපෙන්වීමක් (Guideline) ලෙස පමණක් භාවිත කරන්න.
* *හදිසි කාලගුණ විපර්යාස වලදී ශ්‍රී ලංකා කාලගුණ විද්‍යා දෙපාර්තමේන්තුව සහ නාරා (NARA) ආයතනය නිකුත් කරන නිල නිවේදන අනුගමනය කරන්න.*
